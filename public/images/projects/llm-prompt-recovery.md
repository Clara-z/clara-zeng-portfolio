## Overview

**Silver Medal | Top 3.4% | 75th out of 2,175 teams**

This Kaggle competition challenged participants to reverse-engineer the prompts used to transform text using large language models. Given an original text and its rewritten version (generated by Google's Gemma), the task was to predict the prompt that produced the transformation.

## Technical Approach

### Model Selection

I chose **Mixtral-8x7B-Instruct-v0.1**, a 46 billion parameter Mixture-of-Experts (MoE) model, for its strong instruction-following capabilities and ability to understand nuanced text transformations.

### Parameter-Efficient Fine-Tuning with QLoRA

To fine-tune this massive model on consumer hardware, I implemented **QLoRA** (Quantized Low-Rank Adaptation):

```python
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4",
)

peft_config = LoraConfig(
    lora_alpha=16,
    lora_dropout=0.05,
    r=64,
    bias="none",
    task_type="CAUSAL_LM",
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj", "lm_head"
    ],
)
```

**Key configurations:**
- **4-bit NF4 quantization** with double quantization for memory efficiency
- **LoRA rank (r) = 64** for sufficient model capacity
- **Target modules**: All attention projections + MLP layers + language model head

### Custom Loss Function

The competition used **Sharpened Cosine Similarity (SCS)** as the evaluation metric. Rather than using standard cross-entropy loss, I implemented a custom `SFTTrainer` that directly optimizes for the competition metric:

```python
class CustomSFTTrainer(SFTTrainer):
    def SCS(self, submission, ground_truth, model):
        submission_embedding = model.encode(submission)
        ground_truth_embedding = model.encode(ground_truth)
        
        def sharpened_cosine_similarity(vec1, vec2, exponent=3):
            cosine_similarity = np.dot(vec1, vec2) / (
                np.linalg.norm(vec1) * np.linalg.norm(vec2)
            )
            return cosine_similarity ** exponent
        
        return sharpened_cosine_similarity(
            submission_embedding,
```

## Key Takeaways

1. **Custom loss functions matter**: Directly optimizing for the competition metric (SCS) rather than cross-entropy significantly improved results.

2. **QLoRA enables large model fine-tuning**: 4-bit quantization made it possible to fine-tune a 46B parameter model on a single GPU.

3. **MoE models excel at diverse tasks**: Mixtral's mixture-of-experts architecture proved effective for understanding varied text transformation styles.

4. **Semantic similarity > token matching**: Using sentence embeddings for loss computation allowed the model to learn prompt semantics rather than memorizing exact phrasings.
